# Research Atlas

Research Atlas is a Git-based project management and portfolio template for researchers.

It helps researchers document projects, tasks, progress updates, figures, outputs,
methods, and milestones in a version-controlled repository and publish them as a
static website using GitHub Pages, GitLab Pages, or another static hosting service.

It is designed for researchers, scientific programmers, research software engineers,
PhD students, postdocs, and academic groups who want a lightweight way to track
ongoing work and showcase completed projects.
